# Lock Screen Signals

A free-source monitor for public discussion about Glance, Unity Aura and Android lock-screen advertising.

Sources: Reddit public archive (Arctic Shift), Bluesky, Hacker News, Google News RSS. No X collection or paid APIs.

The dashboard is a proof of concept. It is not a statistically representative sentiment survey. Reddit archive data may be delayed or incomplete. API/site policies and data deletion obligations still apply even to personal projects.

Setup and implementation details will be added with the application source. GitHub Pages must be configured to use **GitHub Actions** under Settings → Pages.
